# Prompt adicional para legendas

Este arquivo e anexado automaticamente ao prompt base do script
`execution/generate_caption.py`.

Use este espaco para regras fixas da sua marca.

Exemplo de regras (edite como quiser):
- Escreva em portugues brasileiro com tom humano e direto.
- Evite promessas absolutas e afirmacoes sem prova.
- Sempre termine com uma chamada para acao curta.
- Inclua no maximo 1 emoji por paragrafo.
- Utilize apenas 3 hashtags
- Faça sempre o post com um estilo cartoonizado, clean e moderno
